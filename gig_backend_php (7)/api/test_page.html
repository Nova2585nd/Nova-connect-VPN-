تست APIهای Gig Backend

هر کارت یک API است؛ مقدارهای تستی از قبل پر شده‌اند و می‌توانی تغییرشان بدهی. زیر هر کارت دستور curl معادل هم نوشته شده.

«تست همه» داده‌ی واقعی در دیتابیس می‌سازد (یک کاربر، یک اطلاعیه و ...) و قیمت هر گیگ را عوض می‌کند. نسخه‌ی تستی اپ را خودش حذف می‌کند.

دستورهای curl برای ترمینال لینوکس، مک و Git Bash هستند. در CMD ویندوز به جای ' از " استفاده کن و داخل JSON هر " را به \" تبدیل کن.
