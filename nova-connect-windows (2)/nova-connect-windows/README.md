# Nova Connect

کلاینت ویندوزی ساده برای اشتراک‌های سازگار با Xray (VLESS، VMess، Trojan، Shadowsocks).

## ساخت (روی ویندوز ۶۴ بیتی با Node.js 20+)
```
npm install
npm run icon          # ساخت assets/icon.png از لوگوی SVG
npm run fetch-xray    # دانلود Xray با بررسی SHA256
npm start             # اجرای آزمایشی
npm run dist          # خروجی EXE در پوشه dist (نصب‌کننده + نسخه Portable)
npm test              # تست منطق تجزیه اشتراک و انتخاب سرور
```
کاربر نهایی به Node.js نیاز ندارد.

## محدودیت‌های شفاف نسخه ۱
- دو حالت اتصال دارد: **پروکسی سیستم** (پیش‌فرض) و **TUN** (همه برنامه‌ها؛ نیازمند ادمین، با tun2socks و Wintun). در TUN ممکن است DNS و IPv6 بعضی برنامه‌ها کاملاً از تونل عبور نکند.
- زبان رابط فقط فارسی است. بررسی خودکار نسخه جدید ندارد (فقط شماره نسخه نمایش داده می‌شود).
- لایسنس Xray-core (MPL-2.0) را هنگام انتشار رعایت کنید.
